
# Citing PSIQIT

If you use PSIQIT in your research, please cite it to help others discover the project and give proper credit to the developers.

## Why Cite?

Citing PSIQIT helps:
- **Acknowledge** the work that went into developing the library
- **Enable reproducibility** by specifying the exact version used
- **Support** continued development of open-source quantum software
- **Build** a community around quantum computing tools

## Citation Formats

### BibTeX (for LaTeX)

```bibtex
@software{psiqit2026,
  author       = {PSIQIT Contributors},
  title        = {PSIQIT: Python Scientific Quantum Information Toolkit},
  month        = sep,
  year         = 2026,
  publisher    = {GitHub},
  version      = {1.0.3},
  doi          = {10.5281/zenodo.XXXXXXX},
  url          = {https://github.com/psiqit/psiqit}
}
```

### APA Style

```
PSIQIT Contributors. (2026). PSIQIT: Python Scientific Quantum Information Toolkit (Version 1.0.3) [Computer software]. GitHub. https://github.com/psiqit/psiqit
```

### MLA Style

```
PSIQIT Contributors. PSIQIT: Python Scientific Quantum Information Toolkit. Version 1.0.3, GitHub, 2026, https://github.com/psiqit/psiqit.
```

### Chicago Style

```
PSIQIT Contributors. "PSIQIT: Python Scientific Quantum Information Toolkit." Version 1.0.3. GitHub, 2026. https://github.com/psiqit/psiqit.
```

### IEEE Style

```
[1] PSIQIT Contributors, "PSIQIT: Python Scientific Quantum Information Toolkit," Version 1.0.3. GitHub, 2026. [Online]. Available: https://github.com/psiqit/psiqit
```

## Example Usage in Papers

### In the Methods Section

```
All quantum circuit simulations were performed using PSIQIT (Version 1.0.3) 
[1], an open-source Python library for quantum information processing. 
The variational quantum eigensolver (VQE) algorithm was implemented using 
the built-in VQE class with the BFGS optimizer.
```

### In the Acknowledgments

```
We thank the developers of PSIQIT for providing the quantum simulation 
framework used in this work.
```

## Version Information

When citing PSIQIT, please include:
- **Version number** (e.g., 1.0.3)
- **Date accessed** (for reproducibility)
- **GitHub URL**: https://github.com/psiqit/psiqit

You can find the version by running:
```python
import psiqit
print(psiqit.__version__)
```

## DOI (Digital Object Identifier)

A DOI provides a permanent, citable link to the software. We are working on registering a DOI through Zenodo. Once available, it will be included in the citation formats above.
