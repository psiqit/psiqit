
# Changelog

All notable changes to PSIQIT will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.3] - 2026-09-10

### Added
- Comprehensive tutorial documentation (6 tutorials)
- Advanced use cases (Quantum Teleportation, NISQ Noise Simulation, VQE Chemistry)
- Auto-generated API documentation using mkdocstrings
- Contributing guidelines and community resources

### Improved
- Enhanced `expectation()` function to handle flexible argument ordering
- Better error messages for dimension mismatches
- Improved Lindblad solver performance

### Fixed
- Fixed statevector normalization in measurement functions
- Corrected qubit ordering documentation

## [1.0.2] - 2026-08-29

### Added
- Variational quantum algorithms module (VQE, QAOA, ADAPT-VQE, SSVQE, TDVP)
- Quantum error correction codes
- Visualization tools for quantum circuits
- Noise cancellation utilities

### Improved
- Faster statevector simulation engine
- Better memory management for large circuits

## [1.0.1] - 2026-07-31

### Added
- Core quantum module (states, operators, measurements)
- Circuit builder with gate library
- Basic quantum algorithms (Grover, QFT)
- Lindblad dynamics solver

### Initial Release
- First public release of PSIQIT
- Documentation site launched
